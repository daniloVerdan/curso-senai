# Curso SENAI — Desenvolvimento Web

Repositório criado para organizar e compartilhar minha evolução durante os estudos de desenvolvimento web no SENAI.

Aqui ficam exercícios, atividades práticas, anotações e projetos desenvolvidos ao longo do curso.

## 🎯 Objetivos

- Praticar os conceitos aprendidos em aula.
- Desenvolver o raciocínio lógico e a capacidade de resolver problemas.
- Aprender a criar páginas e aplicações web.
- Registrar minha evolução e manter um histórico dos projetos.
- Construir uma base de conhecimento que possa ser consultada futuramente.

## 📚 Conteúdos e tecnologias

Atualmente, o foco deste repositório é desenvolvimento web.

- **HTML:** estruturação de páginas.
- **CSS:** estilização, layouts e responsividade.
- **JavaScript:** lógica de programação e interatividade.
- **Git e GitHub:** versionamento e organização dos projetos.

### Pastas

- **BACKEND/** — espaço destinado aos estudos e exercícios relacionados ao lado servidor, conforme esse conteúdo for desenvolvido.
- **html-css/** — exercícios e projetos de estruturação e estilização de páginas web.
- **javascript/** — exercícios e projetos de lógica e interatividade com JavaScript.

A organização poderá ser ampliada conforme novos conteúdos e projetos forem adicionados.

## 🚀 Como utilizar

1. Acesse a pasta do assunto desejado.
2. Consulte os arquivos e atividades disponíveis.
3. Para executar os projetos, siga as instruções específicas de cada pasta.

> Os códigos deste repositório têm finalidade educacional e fazem parte do meu processo de aprendizado.
